# Changelog

## 1.0.2

- Fixed the cases grid height so saved case rows remain visible in the cases tab.

## 1.0.1

- Fixed the case list being squeezed out by the inline stage-history grid.
- Moved stage history into its own window and selected a case immediately after saving it.

## 1.0.0

- Initial Windows WPF release with a local SQLite database.
- Persian RTL interface, bundled Vazir font, Persian date input and display.
- Companies, tax cases, stage history, document attachments and follow-up actions.
- Desktop reminders with sound, tray notifications, completion and snooze.
- Maximized startup with standard resize/minimize controls and an optional Windows startup setting.
- Database/document ZIP backups, portable document paths and behavior checks.
